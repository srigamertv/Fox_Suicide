# Fox_Suicide

Cena cinematográfica de roleplay para RedM acionada por comando.

## 🎬 Funcionalidades

- Animação com arma apontada para a cabeça.
- Câmera cinematográfica configurada para a cena.
- Barras cinematográficas opcionais.
- Prompt para atirar ou cancelar.
- Exige pistola/revólver válido e munição.
- Confirmação em duas etapas para evitar ativação acidental.
- Funciona em VORP, RSG ou standalone; framework só é usado para notificação.
- **Sem item de inventário**.

## ⌨️ Comandos

- `/suicide`
- `/sui` como alias padrão

O primeiro uso pede confirmação. O segundo, dentro do tempo configurado, inicia a cena.

## 🛠️ Instalação

1. Coloque `Fox_Suicide` em `resources`.
2. Adicione `ensure Fox_Suicide` no `server.cfg`.
3. Ajuste `shared/config.lua` se quiser mudar comando, armas, textos ou barras cinematográficas.
